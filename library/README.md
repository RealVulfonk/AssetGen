# Готовые модели

Этот каталог входит в Git: новый клон может сразу открыть GLB в веб-мастерской без установленного Blender. Локальная сборка в `out/` имеет приоритет над библиотекой; изменения моделей и текстур всё равно собираются в `out/`, а исходные JSON хранятся в `specs/`.

Обновить библиотеку после изменения и сборки ассетов:

```powershell
python tools/export_library.py
python tools/check_distribution.py
git add library specs presets
```

`manifest.json` содержит имена, размеры и SHA256 всех переносимых файлов. Отчёты сохраняют метаданные и относительные имена, без абсолютных путей машины автора. `.blend` и историю мастерской в этот каталог не включаем: они попадают в полный резервный архив через `python tools/backup_project.py`.

Это снимок последних доступных сборок, а не гарантия, что все JSON уже пересобраны. Старые сборки без отпечатка модели помечаются в мастерской как устаревшие; при перезапекании геометрия собирается заново. Файлы, которые существовали только в отладочных подкаталогах `out/verification`, остаются в резервном архиве.
