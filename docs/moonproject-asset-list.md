# Ассеты для MoonProject

Рабочий список на 22 ноября 2026 года. Приоритеты предлагаются для одного небольшого уровня с тремя маршрутами из диздока MoonProject. Размер полной игры и состав первого прототипа ещё обсуждаются. Источники в репозитории игры — `Docs/GameDesign.md`, `Docs/roadmap.md`, `Docs/interactions.md` и карточки в `Docs/design/`.

Визуальная цель для стартового набора — [ночной двор](references/night-courtyard.png). Камень, дерево и железо проверяем под холодным общим светом и рядом с тёплым фонарём. Отметка «спека» означает наличие исходного JSON в AssetGen. Импортированная модель считается игровой после проверки масштаба, коллизии и нужных реакций в сцене Godot.

## Архитектура — самый высокий приоритет

Это основа для сборки уровней. Список ниже фиксирует модели, которые нужно спроектировать; наличие пункта не означает готовность спеки или GLB.

| Предмет | Варианты |
|---|---|
| Стены | Каменная, кирпичная, деревянная, штукатурка с балками |
| Углы стен | Внутренний, внешний |
| Полы | Каменные плиты, доски, брусчатка |
| Потолки | Деревянный, каменный |
| Арки | Обычная, широкая, проходная |
| Окна | Обычное, арочное, решётчатое, витражное |
| Крыши | Прямая секция, угол, конёк, черепица |
| Колонны | Каменная, деревянная |
| Балки | Горизонтальная, вертикальная, диагональная |
| Перила | Деревянные, железные, каменные |
| Люки | Напольный, потолочный |
| Балконы | Деревянный, каменный |
| Водостоки | Труба, колено, слив |
| Дымоходы | Каменный, кирпичный |

**Модульная сетка.** Стены, полы, крыши и арки проектировать с размерами, кратными сетке, чтобы из них можно было собирать здания как из конструктора. Конкретный шаг сетки пока не задан.

## Первая играбельная миссия

| Что нужно | Минимальный комплект | Что уже есть и чего не хватает |
|---|---|---|
| **Каменная архитектура и маршруты** | Стена, угол, брусчатка, ступени, парапет, дверная и проходная арки, верхний уступ или часть крыши | Есть `pillar`, `door_arch_01`, `house_01` и тестовая плитка пола. Основную геометрию маршрутов собирать в TrenchBroom, для повторяемых деталей подготовить общий набор формы и материалов. |
| **Поверхности для стелса** | Камень и дерево с различимыми шагами. Визуально нужны кладка, брусчатка и доски; аудио можно начать с двух семейств | Есть заготовки материалов AssetGen и тестовая плитка. Нужны связка с игровыми материалами и наборы звуков шагов. |
| **Дверь и преграда** | Дверная рама, отдельное полотно с pivot на петле, ручка или засов. Решётка для перекрытого прохода, если она нужна в планировке | `door` уже виден в gym, есть `door_arch_01` и `cell_bars`. Для игровой двери проверить разделение подвижных частей, коллизию и открывание. |
| **Деревянный ящик** | Один целый штабелируемый ящик, сцена досок и щепок после удара, обугленная стадия и угли для огня | В игре есть тестовые кубы, обломки и сценарий разрушения. В AssetGen есть `plank_broken_*`, `plank_chunk_01`, `plank_splinters_01`. Нужны цельный художественный ящик и согласованные с ним обломки. |
| **Бочка и тяжёлый предмет** | Бочка для заполнения уровня; один тяжёлый толкаемый предмет для физического маршрута | `barrel_01` обновлён в AssetGen и отдельно проверен в Godot. В игровом gym есть более ранняя бочка и тестовая тяжёлая плита. Для бочки нужен игровой prop и подходящая коллизия, если она будет подвижной. |
| **Свет и огонь** | Один тушимый факел или настенный фонарь, крепление, горящее и погашенное состояния; пламя, дым, пар при тушении | Есть `torch` и `candle`. Закрытый фонарь из референса — кандидат для художественного прохода. Для проверки водяной стрелы нужен источник света, который можно потушить по правилам игры. |
| **Инструмент тушения** | Водяная стрела, визуал запуска, всплеск или пар при попадании; временная модель лука, если нужен вид от первого лица | Требование следует из предложенного состава прототипа. Нужны заготовки стрелы, эффекта и звука попадания. |
| **Один страж** | Один читаемый силуэт, риг и базовые анимации стойки, ходьбы, поворота и поиска; звуки шагов и сигнал настороженности | Есть спека `guard` как заготовка формы. Для игры нужны риг, анимации и проверка силуэта при разных состояниях освещения. |
| **Цель миссии и контейнер** | Один предмет кражи с узнаваемым силуэтом и один сундук или шкаф с отдельной крышкой или дверцей | Есть `chest`, `ironbound_chest_01`, книжные полки и свитки как заготовки. Конкретный предмет кражи зависит от задания уровня. |
| **Магия и обратная связь** | Эффект масштаба, сигнал отказа при нехватке места и эффект выбранной способности перемещения | Для иконок и предметов можно начать со свитка-заготовки. Блинк и левитация остаются вариантами, форма способностей и их носители ещё обсуждаются. |
| **HUD, инвентарь и звук** | Индикатор света, сигнал обнаружения, подсказка взаимодействия, временные иконки цели, стрелы и магии. Звуки удара дерева о камень, разрушения, огня, тушения, двери и магии | Предлагаемый минимум для плейтеста. Понадобится отличать звуки, которые слышит игрок, от событий, на которые реагирует страж. |

## Художественный проход после плейтеста

| Группа | Кандидаты из референса и текущего каталога |
|---|---|
| Двор и фасады | Фахверковые панели, крыша и черепица, водосток, дымоход, оконные рамы и ставни, тёплые окна, синие тени, неровные края брусчатки. Использовать существующие `house_01` и семейство `window_*` там, где подходят по форме. |
| Интерьеры | Стол, стул, скамья, стеллаж, сундук, посуда, урны, свечи и свитки. Для большинства уже есть исходные спеки. |
| Стимпанк | Латунная труба, крепления, манометр или другой настенный прибор из референса. Игровое назначение зависит от планировки и механик. |
| Склеп, если нужен уровню | Гроб, череп с полостями, кости, надгробия, решётки и каменные ниши. Есть `coffin`, `skull_01`, `bone`, `grave_*` и `cell_bars`. |
| Наружные зоны, если нужны уровню | Камни, мост, деревья, пни и подлесок. В AssetGen уже есть `bridge_01`, `rock_*` и семейства флоры. |
| Контент следующих этапов | Дополнительные NPC и анимации, сюжетный реквизит, зелья и алхимическая утварь, другие стрелы и эффекты, новые наборы окружения по списку уровней. |

## Очередь для AssetGen

1. **Архитектурный конструктор.** Проектировать набор из таблицы выше с учётом кратности размеров сетке. Это приоритет автора от 22 ноября 2026 года; первый игровой срез набора описан в пункте 3.
2. **Ящик и обломки.** Получить первый художественный prop, который можно носить, ставить в стопку, ронять и ломать в имеющемся gym.
3. **Камень и дерево для одной сцены.** Собрать набор стены, арки, ступени и пола. Довести бочку и дерево ящика по референсу.
4. **Дверь и свет.** Подготовить подвижное полотно и один настенный источник света с состояниями для проверки стелса.
5. **Сундук и предмет кражи.** Подготовить цель, которую можно разместить за дверью, у стража или на альтернативном маршруте.
6. **Страж, стрела, HUD и звук** идут параллельно со сборкой уровня. Для части этих задач нужны Godot, риг или аудио, а AssetGen даёт только исходную модель.
