# TD-013 · Семантическая проверка геометрии до экспорта

Приоритет — P1. Тип — architecture/code/geometry. Объём — M.
Статус — предложено. Доказательство — воспроизведено на схеме.

## Проблема и доказательство

JSON Schema ограничивает типы и диапазоны, но не проверяет простоту контура и вырожденный scale. На текущей схеме подтверждены `valid=True` для:

- `extrude` с самопересекающимся bow-tie контуром `[0,0] → [1,1] → [0,1] → [1,0]`;
- `box` с `scale: [0,1,1]`, который схлопывает геометрию по оси.

[`p_plane`/`p_extrude`](../../blender/build_model.py#L73-L86) напрямую создают BMesh. Итоговый report проверяет triangles и dimensions, но не degenerate faces/нормали. Полноценная shell validation существует только для cutout operands в [`cutouts.py:15-27`](../../blender/cutouts.py#L15-L27).

## Сценарий влияния

Схема принимает спеку, Blender создаёт пересекающиеся/нулевые грани или экспорт падает глубоко в стадии. Для low-poly формы ошибка проявляется в Godot как невидимая поверхность, неверная нормаль или нестабильная коллизия.

## Границы

Не строить общий expensive self-intersection solver и не требовать, чтобы весь joined prop был одним manifold: он законно состоит из отдельных деталей. Проверять простой 2D outline, конечные числа, нулевой scale и базовое качество per-part/итоговых граней.

## Минимальный план

1. Добавить семантический validator поверх JSON Schema с путём ошибки до `parts[i].points/scale`.
2. Проверять самопересечение и нулевую площадь простого outline; отклонять non-finite JSON значения.
3. После построения измерять нулевые площади и базовые нормали; для cutouts сохранить существующие строгие shell checks.
4. Проверить валидные open `lathe` vessels и `plane` без нового требования закрытости.

## Приёмка

- Два воспроизведённых примера отклоняются до запуска Blender с конкретным полем.
- Валидные plane/extrude/lathe и старые production specs проходят.
- Нулевая/вырожденная грань не попадает молча в GLB; ошибка связывается с частью.
- Нет ложного требования, что joined mesh должен быть одной замкнутой оболочкой.
