# Сброс параметров материала к значениям по умолчанию

Статус — готово.

## Запрос и приёмка

- Добавить кнопку сброса в «Параметры материала». Значения берутся из схемы для текущего режима и рецепта, а не из сохранённой спеки.
- Кнопка меняет черновик: применяется к выбранным моделям только после перегенерации. Выбор карты, палитры, режима и рецепта сохраняется. «Сбросить изменения» по-прежнему возвращает сохранённый рецепт.
- Существующие пользовательские изменения apple_01, bench_01 и bookcase_01 не менять и не коммитить.

## План

1. Воспроизвести отсутствие сброса к дефолтам и добавить действие по default из схемы.
2. Проверить обычный рецепт и image, сохранение выбора источника и возврат к сохранённым настройкам.

## Сообщённые баги

- **B1 · Нет сброса к дефолтам · исправлен.** Автор не мог вернуть параметры материала к значениям по умолчанию. В панели был только «Сбросить изменения», который очищает patch и возвращает сохранённые значения. Добавлена отдельная кнопка выставления default текущего рецепта; исходный сценарий проверен в браузере.

## Решения

- 2026-11-21 — сбрасываются только поля раскрывающегося раздела «Параметры материала», имеющие default в схеме. Карта, её масштаб/влияние, палитра и режим находятся в отдельных разделах и не меняются.

## Результат и проверка

- Исходное поведение подтверждено кодом `reset`: `state.patch = {}`. Действия выставления default не было.
- Добавлена кнопка «Вернуть параметры по умолчанию» в начале раскрываемого раздела; значения извлекаются из того же набора полей схемы, из которого строится форма, включая `$ref`.
- Проверено в браузере: произвольные brightness=0.7 и contrast=2.5 возвращаются к 0 и 1; coopered_wood получает seam_width=0.06 и сохраняет рецепт/выбранную карту. В image яркость возвращается к 0, режим и изображение не меняются. «Сбросить изменения» после этого возвращает сохранённую яркость бочки 0.08 и очищает черновик. Проверены обычный и специализированный рецепты, режим RGB и обратимость сброса.
- `node --check web/app.js` и `git diff --check` — успешно. Запекание не запускалось, спеки не менялись. Превью — `.workbench/material-defaults-button.jpg`.
