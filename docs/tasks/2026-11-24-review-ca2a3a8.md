### Результат исправлений

- **P2, Workbench:** `patched_spec` удаляет `pbr_detail` при итоговом режиме, отличном от `image`. Проверены переходы `wall_stone_01/stone` в procedural и mixed через `validate_candidate`; оба кандидата принимаются.
- **P2, UV:** временная `AssetGenPBRProjection` удаляется после Normal/Roughness bake до сохранения `.blend` и экспорта. `verify_outputs` теперь требует ровно `TEXCOORD_0` у PBR-примитивов обоих GLB; повторная сборка стены прошла.
- **P2, splitter:** проверка существования и публикация комплекта защищены эксклюзивным `.<name>.split.lock`. Два синхронно запущенных CLI без `--force` дают один успешный комплект; второй процесс завершается с отказом, смешивания панелей нет, lock после завершения удаляется. После аварии оставшийся lock можно удалить вручную по пути из ошибки.
- **P3, Godot copy:** `copy_to_godot` удаляет Normal/ORM в назначении, если соответствующих ключей нет в новом отчёте. Тест выполняет PBR-копирование, затем legacy-копирование и проверяет удаление stale карт при сохранении albedo.
- **P3, универсальный A/B:** базовый режим требует видимый меш и хотя бы один StandardMaterial3D с Normal/Roughness, но не ограничивает треугольники, размер карт или число материалов. Проверки 12 треугольников, 512 × 512 и коллизии включены только при дополнительных wall-аргументах. README описывает оба режима.

## Результат и проверка

- P2. В Workbench переключение материала stone у wall_stone_01 в procedural или mixed сохраняет pbr_detail. Проверены оба патча из UI через patched_spec и validate_candidate. Кандидат в обоих случаях отклоняется до постановки задания в очередь.
- P2. После чистой сборки в обоих GLB помимо TEXCOORD_0 присутствует TEXCOORD_1 из временной проекции. Его координаты по U от −1 до 1, по V от −1 до 3. Такой слой непригоден как UV2 для карты освещения. Штатная проверка пропускает его, поскольку сравнивает только индексы UV у текстур.
- P2. Два вызова split_sheet с разными входными изображениями и одинаковым выходным префиксом завершились успешно без --force. Потоки синхронизированы перед первым crop после проверки наличия файлов. Запись через os.replace перезаписывает результаты другого запуска.
- P3. Два последовательных вызова copy_to_godot во временную папку, сначала с PBR, затем с одним albedo, оставили прежние Normal и ORM в назначении.
- P3. README предлагает verify_pbr_import.gd для приёмки других материалов. Скрипт до съёмки требует ровно 12 треугольников и один материал, даже когда дополнительные пути к стене и префабу не переданы.
- Команды python -m unittest discover -s tests -p "test_*.py" (34/34), python assetgen.py validate-texture wall_stone_01, стадии model и texture с --no-copy в отдельном ASSETGEN_OUT, затем python tests/verify_outputs.py wall_stone_01 --out с тем же каталогом завершились успешно. Обе версии GLB разобраны из чистой сборки. Визуальный A/B в Godot в этом ревью не запускался.
