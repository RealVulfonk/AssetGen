# Явный источник поверхности: изображение, процедура, смешивание

Статус — готово.

## Запрос и приёмка

- После обсуждения автор поручил разделить способы получения поверхности: RGB изображения, процедурный рецепт и дополнительный смешанный режим.
- Приёмка: UI показывает активный способ и только относящиеся к нему настройки; image bake переносит цвет изображения, учитывает яркость/контраст и сохраняет материалы/альфу; procedural игнорирует карту; mixed сохраняет прежнее поведение. Старые спеки без нового поля собираются как раньше. Массовая смена режима не переносит чужой рецепт целиком.
- Существующая пользовательская правка `specs/textures/bookcase_01.json` сохраняется и не входит в коммит этой задачи. Во время работы также появилась правка `specs/textures/apple_01.json`; она сохранена и исключена из коммита.

## План

1. Добавить `source_mode` в схему и baker с обратной совместимостью; проверить цвет численным bake.
2. Разделить UI и пакетные изменения на три режима; сохранить свёрнутые параметры.
3. Проверить старую и новую спеку через CLI, браузерный сценарий и diff; обновить документацию.

## Решения

- 2026-11-21 — `source_mode`: `procedural`, `image`, `mixed`. Без поля прежний материал с `source_detail` остаётся mixed, без карты — procedural. Процедурный рецепт сохраняется в JSON как неактивная настройка при image, чтобы переключение назад не теряло параметры.
- 2026-11-21 — в image используются RGB/sRGB карты с прежней объектной box-проекцией; AO/edge и свойства поверхности остаются общими. Яркость и контраст применяются к линейным RGB. Привязка всего атласа к палитре несовместима с исходным RGB; при явном выборе image в мастерской выключаем quantize для атласа и показываем это в интерфейсе. Схема отклоняет image + quantize=true.
