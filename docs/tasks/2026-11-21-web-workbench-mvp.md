# Локальная мастерская AssetGen — MVP

Статус — готово.

## Запрос и приёмка

- Реализовать MVP по [обсуждению](2026-11-21-web-workbench-brainstorm.md), проверить stash и закоммитить оставшуюся работу.
- Приёмка: локальный запуск одной командой, каталог реальных моделей с поиском и множественным выбором, синхронные текстурированный и серый 3D-виды, выбор тега материала, фактуры из presets/textures и параметров процедурного рецепта, пакетная очередь texture --no-copy со статусами и ошибками.
- Исходные рецепты сохраняют специфические параметры; явное редактирование выбранных полей. Запекание только по кнопке. До изменения спеки сохраняется резервная копия. Перенос в игру и полное RGB изображения не входят в MVP.

## План

1. Проверить и отдельным коммитом сохранить ранее накопленные изменения; stash не удалять.
2. Добавить локальный сервер над CLI, каталог и последовательную очередь, браузерный viewer и редактор.
3. Проверить API, массовое редактирование разных рецептов, сбой задания и обычный сценарий в браузере; выполнить контрольное запекание и просмотр diff.

## Решения

- 2026-11-21, продолжение — по просьбе автора скрыть «Параметры материала» в свёрнутый по умолчанию блок. Приёмка: параметры раскрываются кликом, остаются редактируемыми и сохраняют изменения при сворачивании. Проверить браузером и просмотреть diff.

- 2026-11-21 — локальный Python-сервер и статический JS viewer. Требуется доступ к установленному Blender и существующим файлам; облачная публикация не нужна. Браузерные зависимости поставляются локально через npm с зафиксированной версией.
- 2026-11-21 — stash пустой; работа находится в рабочем дереве ветки initial-setup. Автор явно поручил коммит оставшейся работы. Сохраняем её до реализации MVP отдельным коммитом.

## Результат и проверка

- До реализации: 14 Python-тестов проходят. Существующие изменения ещё не являются результатом MVP.
- Накопленная работа сохранена отдельным коммитом `3b6054d`; stash пустой, его содержимое не применялось и не удалялось.
- Реализованы `workbench.py`, статический UI в `web/`, локальная зависимость Three.js с lockfile, инструкции запуска в README и проверки границ в `tests/test_workbench.py`.
- Очередь использует штатный `assetgen.build_stage` напрямую: это позволяет передать снимок рецепта без временной записи в рабочую спеку. Сборка идёт под штатной блокировкой в отдельный каталог; после успеха публикуются файлы и рецепт. Вызов копирования в Godot отсутствует.
- В браузере проверены поиск по `barrel_`, выбор обеих моделей, выбор изображения, изменение яркости, сброс правок, запуск партии и реальные текстурированный/серый виды. Консоль без ошибок. Партия `barrel_01` + `barrel_02` успешно прошла Blender; `python tests/verify_outputs.py barrel_01 barrel_02` подтвердил 2 модели и 2 текстурированных GLB.
- Через HTTP запущен ранее несобранный `apple_01`: модель автоматически построена, текстура запечена, задание завершено. `python tests/verify_outputs.py apple_01 barrel_01 barrel_02` подтвердил все 3 комплекта. Художественные параметры контрольных ассетов сохранены; изменения форматирования от первого прогона убраны.
- Проверены два слабых места: различающиеся рецепты дерева сохраняют собственные параметры при общей правке; имитация отказа Blender не меняет исходный JSON/GLB и не останавливает следующий объект. Дополнительно проверены полная валидация партии до enqueue, очистка устаревших коллизии/lighting-preview при публикации и резервная копия заменяемых файлов.
- Исправлено при проверке: числовые значения вроде `0.095` не должны блокироваться шагом HTML input `0.01`; теперь числовой ввод принимает произвольную точность. Замена картинки переносит только имя карты, сохраняя индивидуальный масштаб и силу фактуры.
- Локальный порт 8765 запрещён Windows (WinError 10013), рабочий порт по умолчанию — 5173. Первый запуск требует `npm --prefix web ci`, затем `python workbench.py --open`; после установки интернет не нужен.
- Ограничения MVP: точный материал виден после bake, RGB исходника не переносится; состав custom layers редактируется в JSON; откат из резервной копии ручной. История не очищается автоматически. При аварийном завершении процесса во время публикации возможен частично обновлённый набор; backup/manifest.json сохраняется до первой замены. Между отдельными заменами файлов публикация не является транзакцией для одновременного читателя.
- Итоговые проверки: `python -m unittest discover -s tests -p 'test_*.py' -v` — 20 тестов OK; `node --check web/app.js`, `node --check web/viewer.js`, `python -m py_compile workbench.py` и `git diff --check` — успешно. HTTP-проверки подтверждают доступность страницы и отказ для чужого Origin/Host и traversal за каталог web.
- Финально в браузере проверено вращение: обе камеры показывают одинаковый новый ракурс. Превью сохранено локально в `.workbench/workbench-preview.jpg` (не входит в Git). Приложение открыто по `http://127.0.0.1:5173`.
- Продолжение: «Параметры материала» переведены в нативный `details/summary`, по умолчанию закрытый. Состояние раскрытия сохраняется при перестроении редактора в текущей сессии. В браузере проверены два сценария: поля скрыты после загрузки; яркость `0.12` остаётся после сворачивания/раскрытия. Сброс настроек также сохраняет раскрытое состояние.
