# Подготовка AssetGen к клонированию и сохранению в GitHub

Статус — в работе (публикация подготовленного проекта).

## Запрос и приёмка

- Проверить возможность выложить проект в GitHub без потери работы и подготовить всё необходимое для клонирования другими людьми.
- Приёмка: текущие настройки сохранены в Git, новый клон устанавливается по README и показывает готовые модели; локальные Blender-пути не обязательны; исходные рецепты/карты и готовые GLB сохранены, игнорируемые рабочие результаты и история отдельно архивированы с контрольными суммами; есть проверка чистого клона.
- Внешний remote не настроен. Публикация/создание репозитория не выполняются без конкретного назначения. Публичная лицензия не назначается автоматически.

## План

1. Проверить tracked/ignored-файлы, зависимости, пути и локальные изменения; сохранить резервный архив.
2. Добавить переносимую конфигурацию, версионируемую библиотеку готовых моделей и инструменты проверки/сохранения.
3. Проверить чистый клон, документацию, размеры и текущие рецепты; сделать коммит и Git bundle.

## Решения

- 2026-11-22, публикация — автор указал `https://github.com/RealVulfonk/AssetGen.git`. Проверка GitHub API показала public; после явного сообщения об этом автор подтвердил отправку в открытый доступ. Это заменяет прежнее решение о приватном доступе. Удалённый репозиторий пуст; публикуем текущую историю в main без force push.

- 2026-11-22 — исходный код и JSON уже в Git, но out и .workbench игнорируются, поэтому новый клон показывал бы пустую мастерскую. Готовые переносимые GLB/превью выделяем в tracked library, а .blend, диагностические файлы и историю сохраняем отдельным полным архивом вне репозитория. Это сохраняет возможность просмотра без Blender и не смешивает runtime-кэш с распространяемой библиотекой.
- 2026-11-22 — пять пользовательских текстурных спек (apple_01, barrel_02, bench_01, bookcase_01, bridge_01) входят в сохранение по прямому поручению автора «ничего не потерять».
