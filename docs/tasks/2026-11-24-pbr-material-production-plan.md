# Зафиксировать план производства PBR-материалов

Статус — готово.

## Запрос и приёмка

- Запрос автора — сохранить переданный перечень материалов, приоритеты по локациям и порядок первых десяти PBR-текстур. Границы — документация; генерация изображений, спеки и код не меняются. Посторонние изменения спек и референсов сохранить.
- Готово, когда полный план доступен в `docs/`, связан с шаблоном генерации и содержит исходные рекомендации по палитре, вариантам, маскам и формату триптиха.

## План

1. Создать отдельный документ с категориями материалов и назначением по локациям.
2. Сохранить порядок первых десяти текстур и правила повторного использования через шейдеры.
3. Добавить ссылку из шаблона генерации, проверить diff и локальные ссылки.

## Решения

- 2026-11-24 — выбран отдельный `docs/pbr-material-production-plan.md`, а не расширение короткого промпта всем планом. Основание — промпт должен оставаться удобным для копирования, а производственный план нужен как самостоятельный ориентир. Чеклист в промпте сохраняется как рабочий список ближайших генераций; подробный документ фиксирует долгосрочные варианты и приоритеты.

## Результат и проверка

- Изменилось — создан `docs/pbr-material-production-plan.md` со всеми пятью категориями, особыми материалами локаций, первыми десятью текстурами, форматом триптиха и правилом вариаций через шейдеры. В шаблон генерации добавлена ссылка на план; карточка фиксирует выбор хранения.
- Проверено — ссылка из `docs/prompts/chatgpt-pbr-texture-sheet.md` ведёт к созданному файлу, формулировки исходного перечня сохранены. `git diff --check` завершился без ошибок. Код, спеки и референсы не изменялись.
