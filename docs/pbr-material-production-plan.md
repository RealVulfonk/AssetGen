# План производства PBR-материалов

Рабочий ориентир от 24 ноября 2026 года для города, замка, храма, катакомб, канализации и пещер. Генерация выполняется по [короткому шаблону PBR-листа](prompts/chatgpt-pbr-texture-sheet.md); ближайшие результаты отмечаются в его чеклисте.

## Единый формат

Для каждого основного материала используем горизонтальный PNG 3072 × 1024 из трёх согласованных панелей 1024 × 1024:

1. Base Color;
2. Normal в tangent-space OpenGL / Y+;
3. Roughness как линейная grayscale-карта.

Физический размер каждой панели — 2 × 2 м. Для реального использования необходимо проверять бесшовность, совпадение деталей и корректность карт, а не полагаться только на визуальную генерацию. После разрезания обязательны bake и Godot A/B.

## 1. Камень и архитектура — главный приоритет

Для города, замка, храма и катакомб.

| Материал | Где использовать | Приоритет |
|---|---|---|
| Тёмная каменная кладка | Городские стены, замок | Высокий |
| Крупные каменные блоки | Фундаменты, башни, арки | Высокий |
| Старая кирпичная кладка | Канализация, подвалы | Высокий |
| Серая штукатурка | Фахверковые дома | Высокий |
| Каменные плиты пола | Замок, храм, коридоры | Высокий |
| Брусчатка | Улицы, дворы, площади | Высокий |
| Мшистая кладка | Катакомбы, заброшенные здания | Средний |
| Светлый известняк | Храм, богатые здания | Средний |

Для нашей палитры камень лучше делать холодным, серо-синим или серо-коричневым, с умеренным контрастом между блоками.

## 2. Дерево

| Материал | Где использовать |
|---|---|
| Тёмные дубовые доски | Полы, двери, мебель |
| Вертикальные старые доски | Перегородки, сараи, заборы |
| Грубые деревянные балки | Каркасы зданий |
| Светлые потёртые доски | Бедные дома, чердаки |
| Почерневшее влажное дерево | Канализация, причалы |
| Старая деревянная черепица | Крыши пригорода |

Здесь можно сэкономить: одна качественная текстура дуба с разными цветовыми оттенками материала в Blender позволит получить несколько вариантов.

## 3. Земля и природа

Для парка, пригорода и пещер.

| Материал | Где использовать |
|---|---|
| Утоптанная земля | Тропинки, дворы |
| Грязь с небольшими камнями | Пригород |
| Тёмная трава | Парк, окраины |
| Сухая трава с землёй | Заброшенные территории |
| Лесная почва с листьями | Парк |
| Серый скальный камень | Пещера под городом |
| Влажный скальный камень | Берега подземного озера |
| Гравий и мелкие камни | Пещеры, дороги |

Для больших поверхностей земли и травы пригодятся дополнительные маски смешивания материалов, чтобы не было заметного повторяющегося рисунка.

## 4. Металлы и специальные материалы

| Материал | Где использовать |
|---|---|
| Чёрное кованое железо | Решётки, двери, петли |
| Ржавое железо | Канализация, старые механизмы |
| Потемневшая бронза | Замки, фонари, приборы |
| Медь с патиной | Трубы, стимпанк-элементы |
| Старая красная ткань | Знамёна, ковры |
| Грубая мешковина | Мешки, тюки |
| Тёмная кожа | Экипировка, ремни |
| Мутное стекло | Окна, фонари |

Для металлов необязательно создавать отдельную текстуру на каждый предмет. Часто достаточно общего материала с изменяемыми Metallic, Roughness и цветом.

## 5. Особые материалы для локаций

- **Канализация:** слизистый камень, грязный кирпич, ржавые трубы.
- **Катакомбы:** пыльный известняк, древние каменные плиты, мшистые блоки.
- **Храм:** изношенный светлый камень, цветное стекло, красная ткань.
- **Замок:** полированный, но состаренный каменный пол, тёмное дерево.
- **Пещера:** мокрая скала, глина, каменистый берег.
- **Дождливый город:** существующая брусчатка с управляемой влажностью и лужами через шейдер, а не отдельная текстура на каждую степень намокания.

## Первые 10 текстур

Порядок выбран так, чтобы быстрее собрать первые игровые локации:

1. Тёмная каменная кладка.
2. Каменный пол из крупных плит.
3. Уличная брусчатка.
4. Старая серая штукатурка.
5. Вертикальные деревянные доски.
6. Тёмная кирпичная кладка.
7. Сланцевая черепица.
8. Утоптанная земля с грязью.
9. Скальная поверхность для пещер.
10. Старый металл с умеренной ржавчиной.

## Правило производства

Сначала делаем 10 качественных базовых материалов, а затем получаем варианты через настройки шейдеров, маски грязи, мха и влажности. Так проще сохранять единый стиль и не раздувать количество текстур.
