# Шаблон ChatGPT для согласованного PBR-листа

Замени только `[МАТЕРИАЛ]`; при необходимости измени физический размер панели.

```text
Создай один горизонтальный RGB PNG 3072×1024 из трёх равных панелей 1024×1024 без рамок, текста и разделителей.

Материал: [МАТЕРИАЛ].
Физический размер каждой панели: 2×2 метра.
Стиль: сдержанный стилизованный low-poly game material.

Порядок панелей слева направо:
1. Base Color — собственный цвет материала, без освещения, теней, AO и бликов.
2. Normal — настоящая tangent-space normal map OpenGL / Y+, плоские участки #8080FF.
3. Roughness — линейная grayscale-карта: чёрный = 0, белый = 1.

Все три карты должны описывать ОДНУ каноническую поверхность. Расположение, размер и форма деталей обязаны совпадать по координатам. Не перерисовывай материал отдельно для каждой панели и не создавай Normal простым окрашиванием Base Color.

Вид строго сверху, без перспективы и окружения. Текстура заполняет панели целиком и бесшовно повторяется по горизонтали и вертикали. Умеренная детализация, без чрезмерного шума. Итог — только PNG, без пояснений.
```
